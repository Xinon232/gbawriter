# EZ-Flash Omega references

`src/ezfo_driver.c` (MIT) follows the SD register protocol of:

- the EZ-Flash Omega kernel, https://github.com/ez-flash/omega-kernel
  (`source/Ezcard_OP.c`), and the Omega Definitive Edition kernel,
  https://github.com/ez-flash/omega-de-kernel, both Apache License 2.0;
- ezfo-disc_io by Felix Jones and ApacheThunder,
  https://github.com/ApacheThunder/ezfo-disc_io (release 0.9), Apache
  License 2.0.

No file of those projects is included; their licence text is in
`LICENSE-Apache-2.0.txt`. See `docs/ezflash-omega.md`.
