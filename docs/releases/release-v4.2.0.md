# gbawriter V4.2

Based on gbawriter V4.1. **Physical GBA/Supercard SD saving remains unverified**: keep backups and use disposable documents first.

Files in this release:

- `gbawriter.gba`: the Game Boy Advance ROM.
- `gbawriter-full-controls.pdf`: the manual.
- `SHA256SUMS`.

## Changed

- **Select > File names** always shows the same example date, **13 July 2026**, in the chosen format: `13072026`, `13.07.2026`, `07132026`, `07.13.2026`, `2026-07-13`. Day 13 cannot be a month, so you can see at once which number is the day and which the month. (Before, the row showed the next proposed date, which changed.)
- New File still proposes the day after your newest diary file; only the example in the menu changed.

## Notes

- No change to files, settings or the other screens. Not tested on real hardware.
